## OTA 循环刷机修复 + 定时自动升级（提交 81768a3）
- **用户抓到的严重 bug**：原"开机自动升级"每次上电都重刷巴法云同一固件（静态文件无版本比对）
  → 无限"升级-重启"循环。用户要求改成固定时间。
- **方案**：每天固定小时（默认 4 点，可改 0~23）HEAD 巴法云 bin 链接读 **Last-Modified 头**
  （实测巴法云返回，= OTA 页面的"上传时间"）→ 与 EEPROM 记录的当前固件上传时间比对：
  相同跳过、不同才升级。升级成功后用 otaSetLocalLM() 记录新固件的上传时间。
- **自动升级链接存 EEPROM（128B，网页可自由改）**，空=内置 OTA_AUTO_URL。
- 新增 SNTP（ntp.aliyun.com）对时；新增 /otacheck（JSON：remote/local/same/count）+ 网页「🔍 检查更新」按钮。
- EEPROM 开关区扩到 163 字节：[魔数][flags][hour][LM 32B][URL 128B]。
- 顺带修了 setup 漏调 loadPeriphFlags() 的 bug（外设开关此前根本没从 EEPROM 加载）。
- bin 在桌面 LAND_LED.ino.bin（588KB）。**提醒过用户：新 bin 要传巴法云覆盖，否则定时升级会拉到旧版**

## EEPROM 布局迁移（提交待查：修复 21252 显示）
- 现象：间隔显示 2125（实为 21252）= 旧布局 [2]=小时(4) + [3]=LM首字母('S'=0x53)
  被新布局按 uint16 LE 读成 4|0x53<<8
- 修复：魔数 0xA5→0xA6 触发迁移——位标志字节偏移相同可继承（DHT/红外/自动升级），
  间隔/LM/URL 回默认重新登记；间隔加 43200 分钟(30天)上限，网页/接口同步
- **教训：EEPROM 布局变更必须换魔数做迁移**，只改解释方式不改魔数 = 读到垃圾值

## 修复检查更新显示空时间（已推送）
- 根因：otaFormatLMStr 用 %*3s 跳星期，但 Last-Modified 星期后跟逗号("Sat,")，
  %*3s 只吃 3 字符，逗号留给 %d → sscanf 失败 → 恒返回空串
  → 网页"远程/当前固件上传时间"全空（但原始串比对正常所以"一致"仍显示）
- 修复：%*3s → %*s（跳过整个词元含逗号）
- 顺带修复 GMT+8 换算：原直接 hh+8 会跨日溢出（20:00 GMT → 28 点），
  改为纪元秒换算（days-from-civil 算法）后再 gmtime 格式化

## OTA 最终形态：MQTT 主题推送升级（提交 197f77b）
- 用户定案：MQTT 用自己的服务器；升级固件时往订阅主题发布固件下载链接（http 开头文本），
  自动模式设备收到立即升级；删除 OTA 卡片里的定时检查/检查更新按钮 /otacheck otainterval SNTP
- 卡片保留：链接输入框（placeholder=内置巴法云链接，修改保存后即升级链接）+ 自动模式开关 + 一键升级 + 进度条
- 机制：升级成功记录 bin 的 Last-Modified 到 EEPROM（otaLocalLM），重复推送同一文件自动跳过（防循环刷机）
- 手动一键升级后自动切回手动模式（/ota 路由里 otaAutoEnabled=false）
- 自动模式下手动模式的主题推送被忽略；MQTT 推送用普通 QoS，设备离线时消息会丢
  → 用户需设备上线后重发，或发布时勾选 retain
- 教训：patch() 对"删除类补丁"（new 为空串）不能用 new-in-s 做跳过守卫（空串恒在），
  会导致删除补丁被静默跳过——已改为 old 不在且 new 为空时按"已删除"跳过

## OTA 最终形态 v2：巴法云 firmwareVersion API（提交 2802c6e）
- 用户指出应使用巴法云官方 OTA API（https://cloud.bemfa.com/docs/src/api_ota.html）：
  GET firmwareVersion?openID=私钥&topic=主题&deviceType=1 → JSON{version,url,unix,size,tag}
- 设备按间隔（默认 240 分钟）调此接口，与 EEPROM 记录的版本/上传时间比对，
  有新版本从返回 url 下载刷入，成功后同步新版本号到 EEPROM。首次检查自动登记基准。
- 网页卡片：openID 输入框 + 间隔(分钟) + 自动开关 + 「立即检查并升级」按钮 + 版本信息显示
- HTTPS：WiFiClientSecure setInsecure()（API 是 https）；JSON 用内置 ArduinoJson 7（JsonDocument）
- EEPROM v3（魔数 0xA7）：[4~35] openID、[36~39] lastVersion、[40~43] lastUnix；旧布局迁移开关+间隔
- 教训：多轮补丁叠加易失控（外围补丁与实际文件状态漂移），大改时直接整文件重写更可靠；
  patch() 的 new-in-s 守卫对删除类补丁（new 为空）无效需特判
- bin 在桌面（684KB，Flash 60%——WiFiClientSecure 增加体积）；巴法云上传新 bin 会自动递增版本号
