## OTA 循环刷机修复 + 定时自动升级（提交 81768a3）
- **用户抓到的严重 bug**：原"开机自动升级"每次上电都重刷巴法云同一固件（静态文件无版本比对）
  → 无限"升级-重启"循环。用户要求改成固定时间。
- **方案**：每天固定小时（默认 4 点，可改 0~23）HEAD 巴法云 bin 链接读 **Last-Modified 头**
  （实测巴法云返回，= OTA 页面的"上传时间"）→ 与 EEPROM 记录的当前固件上传时间比对：
  相同跳过、不同才升级。升级成功后用 otaSetLocalLM() 记录新固件的上传时间。
- **自动升级链接存 EEPROM（128B，网页可自由改）**，空=内置 OTA_AUTO_URL。
- 新增 SNTP（ntp.aliyun.com）对时；新增 /otacheck（JSON：remote/local/same/count）+ 网页「🔍 检查更新」按钮。
- EEPROM 开关区扩到 163 字节：[魔数][flags][hour][LM 32B][URL 128B]。
- 顺带修了 setup 漏调 loadPeriphFlags() 的 bug（外设开关此前根本没从 EEPROM 加载）。
- bin 在桌面 LAND_LED.ino.bin（588KB）。**提醒过用户：新 bin 要传巴法云覆盖，否则定时升级会拉到旧版**
- 代码坑：DEBUG_PRINT 宏单参数；char[] 不能直接 + 拼接要包 String；OTA_FLAGS_LM_LEN 漏定义
